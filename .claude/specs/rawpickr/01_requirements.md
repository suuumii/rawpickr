# 要件定義 — RawPickr

**ステータス**: 承認済み（実装完了）
**作成日**: 2026-04-25
**更新日**: 2026-07-11

---

## ユーザーストーリー

### US-01: 日付別フォルダ整理

```
As a 写真ユーザー
I want to Windows で取り込んだ写真が入ったフォルダを選択し、撮影日ごとにサブフォルダへ自動で振り分けたい
So that  撮影日・場所ごとに整理された状態でレーティング作業に入れる
```

**受け入れ条件**:
- [x] 整理元フォルダ（取り込んだ写真が混在しているフォルダ）を選択できる
- [x] 場所名をテキスト入力できる
- [x] JPG の EXIF 撮影日時を読み取り、撮影日ごとにサブフォルダを作成する
- [x] サブフォルダ名は `{YYYYMMDD}_{場所名}_work` 形式とする
- [x] JPG と RAW（.CR2, .CR3, .NEF, .ARW, .RAF など）を同じサブフォルダへ**移動**する
  - 同一ファイル名の RAW も対応する JPG と同じサブフォルダへ移動する
  - RAW 拡張子の大文字小文字を問わず照合する
- [x] RAW のみ存在し対応する JPG がない場合も、RAW の EXIF から撮影日を読み取って整理する
- [x] `.pp3` サイドカーファイルも対応する JPG/RAW と同じフォルダへ移動する
- [x] 整理完了後に作成フォルダ数・移動ファイル数のサマリーを表示する
- [x] 実行前に確認ダイアログを表示する

---

### US-02: 写真閲覧とレーティング付与

```
As a 写真ユーザー
I want to 整理済みフォルダを選択し、JPG・RAW をファイル一覧で確認しながら 1〜5 のレーティングをつけたい
So that  後で現像する価値のある写真を素早く選別できる
```

**受け入れ条件**:
- [x] フォルダ選択ダイアログで対象フォルダを開ける
- [x] フォルダを開くとファイル一覧が表示される
- [x] JPG のみ・RAW のみのファイルにはバッジ（JPG / RAW）を表示する
- [x] ファイルをクリックするとプレビューが大きく表示される
  - JPG: `asset://` プロトコルで直接表示
  - RAW: ファイル内の埋め込み JPEG プレビューを抽出して表示（base64 data URL）
- [x] プレビュー表示中にキーボード（1〜5）でレーティングをつけられる
- [x] レーティングは一覧の右端に星（★）で表示される
- [x] レーティングは次回起動時も保持される（`.ratings.json` で永続化）
- [x] キーボード（← →）で前後の写真に移動できる
- [x] レーティング 0（未評価）にリセットできる（キー: 0）

---

### US-03: EXIF 情報の表示

```
As a 写真ユーザー
I want to 写真を見ながら撮影時のカメラ設定を確認したい
So that  レーティング判断や学習のために撮影条件を把握できる
```

**受け入れ条件**:
- [x] プレビュー画面に以下の EXIF 情報を表示する
  - カメラ機種名
  - レンズ名
  - F 値
  - シャッタースピード
  - ISO 感度
  - 撮影日時
  - 焦点距離
- [x] EXIF が存在しない場合は「情報なし」と表示する

---

### US-04: レーティング済み写真の仕分け（2026-07-11 改訂）

```
As a 写真ユーザー
I want to レーティングがついた JPG・RAW・サイドカーを 1 つの日付・場所フォルダへまとめて移動したい
So that  RAW 現像ソフトで pick した写真だけを、JPG/RAW を分けずに編集できる
```

**受け入れ条件**:
- [x] 「ピックアップ実行」ボタンを押すと確認ダイアログが表示される
- [x] 確認後、レーティング 1 以上のファイル（JPG・対応する RAW・対応する `.pp3`）を、元フォルダと同じ階層に作成する `{YYYYMMDD}_{場所名}` フォルダへ**移動**する（コピーではない）
- [x] 移動先フォルダ名は選択元フォルダ名から自動生成する
  - 元フォルダ名が `{YYYYMMDD}_{場所名}_work` 形式の場合、末尾の `_work` を除去した名前を使う（例: `20260625_京都_work` → `20260625_京都`）
  - 元フォルダ名がこの形式に一致しない場合は、元フォルダ名をそのまま移動先フォルダ名として使う
- [x] 移動先フォルダが既に存在する場合は、そのフォルダにファイルを追加で移動する（上書き・エラーにしない）
- [x] レーティング 0（未評価）のファイルは元フォルダに残す
- [x] 対応する RAW が見つからない場合はスキップしてログに記録する
- [x] 仕分け完了後に件数サマリー（移動件数・スキップ件数）を表示する
- [x] 移動したファイルのレーティングデータ（`.ratings.json`）も移動先フォルダ側に引き継ぐ

**廃止**:
- [x]（廃止）レーティング済み JPG を `{元フォルダ名}_pick` に、対応 RAW を `{元フォルダ名}_raw_pick` にそれぞれコピーする従来方式は本改訂で置き換える

---

### US-05: 写真の削除

```
As a 写真ユーザー
I want to 不要な写真を JPG+RAW まとめて、または RAW のみ削除したい
So that  ストレージを節約しながら整理できる
```

**受け入れ条件**:
- [x] プレビュー画面に「JPG+RAW 削除」「RAW のみ削除」の 2 つのボタンを表示する
- [x] キーボードショートカット（`Delete` キー）でも削除操作を起動できる（モードはダイアログで選択）
- [x] 削除には 2 つのモードがある
  - **JPG + RAW 削除**: 同名の JPG と RAW を両方削除する
  - **RAW のみ削除**: 同名の RAW ファイルのみを削除し、JPG は残す
- [x] 削除実行前に確認ダイアログを表示する（モード・対象ファイル名を明示）
- [x] 削除後はファイル一覧から該当写真が消える
- [x] 削除した写真のレーティングデータも合わせて削除する

## スコープ外（今回は作らない）

- SD カードからの直接取り込み（Windows 標準機能で行う）
- RAW 現像機能
- クラウドへのアップロード
- タグ・キーワード管理
- 顔認識・AI 分類
- 動画ファイルの対応

---

## 想定する操作フロー

```
1. アプリ起動
2. [撮影日でフォルダ分割] タブ → 取り込み済みフォルダ選択 → 場所名入力 → 日付別フォルダへ移動
3. [プレビュー・レーティング] タブ → 整理済みフォルダ選択 → ファイル一覧表示
4. ファイルクリック → プレビュー + EXIF 表示 → キーボードでレーティング（1〜5）
5. 不要な写真は削除ボタンまたは Delete キーで削除
6. [ピックアップ] タブ → ピックアップ実行 → レーティング済み JPG + RAW + サイドカーを `{YYYYMMDD}_{場所名}` フォルダへ移動
```
