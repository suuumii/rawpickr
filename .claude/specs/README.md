# スペックディレクトリ

各機能のスペックはこのディレクトリ以下に管理します。

## 構造

```
specs/
└── {機能名}/
    ├── 01_requirements.md   # 要件定義（Phase 1）
    ├── 02_design.md         # 設計（Phase 2）
    ├── 03_tasks.md          # タスクリスト（Phase 3）
    └── 04_progress.md       # 実装進捗メモ（Phase 4）
```

## ステータス管理

各スペックのステータスは `03_tasks.md` のチェックボックスで管理する。

- `[ ]` 未着手
- `[x]` 完了
